📌 Production System Architecture

This engine demonstrates top-tier systems engineering, low-level bitwise computing, and adversarial game theory:

  • 64-bit Bitboard Representation: The 7×6 grid is mapped into a single 49-bit integer bitmask. Win condition validation executes in 4 bitwise shifts and AND instructions (< 2 nanoseconds), with zero memory allocations.
  • Negamax Formulation: Replaces dual-agent Minimax with a mathematically symmetric $NegaMax(s, \alpha, \beta) = \max (-NegaMax(s', -\beta, -\alpha))$ recursive function.
  • Principal Variation Search (PVS): Searches the first candidate move with a full $[\alpha, \beta]$ window, then uses null-window scout searches $[-\alpha - 1, -\alpha]$ for remaining moves, pruning unpromising branches exponentially faster.
  • Iterative Deepening Search (IDS): Employs time-bounded iterative search with move ordering from previous depth seeding subsequent iterations.
  • Zobrist Hashing & Transposition Table: Incremental $O(1)$ 64-bit state hashing caching evaluation flags (Exact, Lowerbound, Upperbound) and best moves.

🎯 Common Interview Questions & Talking Points

  • Why use Bitboards over 2D Arrays? Bitboards compress the board into CPU registers, eliminating pointer dereferences and cache misses. Win detection drops from looping over 69 lines down to 4 single-cycle SIMD bit shifts.
  • How does PVS improve on standard Alpha-Beta? If move ordering is accurate, subsequent moves are unlikely to beat $\alpha$. Testing with a minimal null window $[-\alpha-1, -\alpha]$ triggers immediate cutoffs without full-width evaluations.
