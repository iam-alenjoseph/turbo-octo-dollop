Minimax Algorithm Architecture

This bot implements an adversarial zero-sum search engine tailored for Connect Four.

1. Minimax Game Tree

The AI models the game as an alternating tree: the AI seeks to maximize utility (+∞) while assuming the human plays optimally to minimize utility (-∞).

2. Alpha-Beta Pruning

Maintains two parameters during depth-first search:

  • Alpha (α): The highest score the maximizing player is guaranteed.
  • Beta (β): The lowest score the minimizing player is guaranteed.

Whenever α ≥ β, the current branch is pruned. This drops time complexity from O(b^d) towards O(b^(d/2)).

3. Move Ordering Optimization

Columns are evaluated center-outward: [3, 2, 4, 1, 5, 0, 6]. In Connect Four, central columns participate in up to 16 four-in-a-row alignments (vs 4 in the corners), forcing rapid alpha-beta cutoffs early in search.

4. Transposition Table

Different move orders often reach identical board layouts. A 64-bit state key caches previously calculated evaluations and optimal sub-moves, eliminating redundant calculations.
